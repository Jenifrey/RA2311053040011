# Stock Trend Visualization using Time Series Analysis

## Overview
This project analyzes stock price trends using time series data. The dataset used is NSEI stock data.

## Steps Performed
1. Data loading
2. Data preprocessing (date conversion, sorting, cleaning)
3. Basic statistical analysis
4. Time series visualization using line plot
5. Trend analysis using 50-day moving average

## Tools Used
- Python
- Pandas
- Matplotlib

## Output
- Stock trend line plot
- Moving average trend plot
